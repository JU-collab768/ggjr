GODFRED GBOR JUNIOR — PERSONAL WEBSITE

This is a complete, responsive static website. It is ready for hosting, but is NOT yet public on the internet. A hosting account and a publishing step are required before Google or other people can visit it.

QUICK PREVIEW
Open index.html in a web browser.

PUBLISHING OPTION: GITHUB PAGES
1. Sign in to GitHub and create a new public repository named godfred-gbor-junior.
2. Upload the CONTENTS of this folder (index.html, styles.css, script.js, assets folder, robots.txt and sitemap.xml) to the repository's main branch.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and / (root), then Save.
5. GitHub will provide a public website address. You can optionally connect a domain you own.
6. Replace YOUR-DOMAIN.example in robots.txt and sitemap.xml with the real published address, then upload the updated files.
7. Add the published website to Google Search Console, verify ownership, and submit the sitemap.

GOOGLE VISIBILITY
Google indexing is not instant and cannot be guaranteed. After publishing, use Google Search Console's URL inspection to request indexing. Keep the website updated and use the same full name consistently on public profiles.
